# 마베드 (mabed)

**버킷츠 Ma Bed 2M+ 모션베드를 폰으로 조작하는 안드로이드 앱.**
제조사(birkits) 앱이 2026년 5월 서비스를 종료해서, 부품 교체 없이 계속 쓰려고 직접 만든 대체 앱이다.
인터넷 서버 없이 **집 와이파이 안에서, 폰이 곧 서버**가 되어 동작한다.

[최신 버전 받기](https://github.com/hshj1426-droid/mabed/releases/latest) · [바뀐 내용](docs/HISTORY.md) · [통신 규칙](docs/PROTOCOL.md)

---

## 설치

1. 폰에서 [최신 릴리스](https://github.com/hshj1426-droid/mabed/releases/latest)를 열고 `mabed-x.y.z.apk` 를 받아 설치한다.
   "출처를 알 수 없는 앱" 경고가 뜨면 이번만 허용한다.
2. 다음 버전부터는 **앱을 켤 때** 새 버전이 있는지 확인하고 설치할지 묻는다. (설정 → 새 버전 확인하고 설치 로도 가능)
   처음 한 번은 "이 출처 허용"을 켜 달라는 안내가 나온다.

안드로이드 7.0 이상. 침대는 **2.4GHz 와이파이만** 쓸 수 있다.

## 처음 연결하기

앱을 처음 켜면 "침대 연결하기" 안내가 순서대로 나온다.

1. 침대 이름 정하기 (폰은 집 와이파이에 연결된 상태)
2. **침대를 설정 모드로** — 침대 밑 컨트롤 박스 나사 4개를 풀고, 안쪽 작은 기판의 micro-USB 단자 오른쪽 **BOOT 버튼을 10초**.
   빨간 불이 빠르게 깜빡이면 된다.
3. 폰 와이파이를 `birkits-` 로 시작하는 이름에 연결하고, **모바일 데이터를 끈다**
4. 침대가 쓸 집 와이파이를 고르고 비밀번호 입력
5. "침대에 넣기" → 폰을 다시 집 와이파이로 → 10초쯤 뒤 연결됨

## 쓰는 법

- **자세** — 평평하게 · 독서 · 다리 올림 · 무중력, 그리고 내 자세 A/B 저장·불러오기
- **조절** — 상체·다리를 슬라이더(옆으로 끌기)나 −/+ 로. 움직이는 동안 `30° → 60°` 처럼 어디서 어디로 가는지 보인다
- **정지** — 화면 맨 아래 빨간 버튼. 그 자리에서 멈춘다
- **무드등 · 스피커** — 스피커를 켠 뒤 폰 블루투스에서 `XDADADZ` 에 연결
- **침대가 여러 대면** — 침대 그림 카드를 **옆으로 쓸거나 ‹ ›** 로 넘긴다. 마지막에 보던 침대부터 열린다
- **설정(오른쪽 위 톱니)** — 이름 바꾸기, 테이블 사용, 각도 맞추기, 침대 추가·넘기기, 짝짓기, 업데이트, 연결 기록

## 가족끼리 쓰기 (폰 여러 대)

침대마다 **주인 폰**이 하나 있고, 다른 폰은 같은 와이파이에서 주인 폰을 거쳐 조작한다.

- **짝짓기 (처음 한 번)** — 두 폰 모두 앱을 연 채로, 한쪽에서 "짝짓기"를 누르고 다른 쪽에서 **허용**.
  짝지은 폰끼리만 서로의 침대를 조작할 수 있다. 이후로는 다시 묻지 않는다.
- **침대를 다른 폰으로 넘기기** — 설정 → 다른 폰으로 넘기기 → 받을 폰 선택 → 안내대로 BOOT 10초.
  받는 폰 메인 화면에 "이 폰에 등록하기"가 뜨면 누른다.
- **앱을 닫으면** 5분 뒤 연결을 모두 끈다(배터리). 그동안에는 다른 폰도 그 폰의 침대를 쓸 수 없다.
  상대방 앱이 닫혀 있어도 그 침대를 쓰고 싶으면 **상대방 폰**에서 설정 → "앱을 닫아도 대기"를 켠다.

## 문제 해결

| 증상 | 해볼 것 |
|------|---------|
| 계속 "기다리는 중" | 폰이 침대와 **같은 공유기**의 와이파이에 있는지. 다른 공유기(다른 주소 대역) 뒤에 있으면 침대가 폰을 못 찾는다 — 메인 화면에 빨간 안내가 뜬다. 그 공유기를 AP(브리지) 모드로 바꾸면 해결 |
| 폰 주소가 바뀌었다는 안내 | 공유기 설정에서 이 폰 주소를 고정(DHCP 예약)하거나, 설정 → 침대 추가하기로 다시 연결 |
| 화면이 꺼진 뒤 한참 지나면 반응이 없다 | 설정 → "배터리 제한 풀기", 그래도 안 되면 "연결 유지 강화" 켜기(배터리 더 씀) |
| 상대 침대(↗)가 안 보인다 | 짝을 지었는지(설정 → 폰 짝짓기), 상대 폰 앱이 열려 있거나 "앱을 닫아도 대기"가 켜져 있는지 |
| 그림·숫자가 실제 각도와 다르다 | 설정 → 각도 맞추기 (끝까지 올렸을 때 실제 각도 입력) |
| 테이블 칸을 움직였더니 다리가 움직인다 | 테이블이 없는 침대다. 설정 → 테이블 "없음" |
| 그 밖에 | 설정 → 연결 기록 보기 화면을 캡처해서 알려주기 |

## 안전

- 모든 통신은 **집 와이파이 안**에서만 한다. 인터넷으로 나가는 건 새 버전 확인(깃허브)뿐이다.
- 폰끼리 명령 창구(9099)는 **짝지은 폰만** 쓸 수 있다. 요청마다 짝짓기 때 나눠 가진 열쇠로 도장(HMAC)을 찍고,
  시각·재사용을 확인한다. 자세한 건 [통신 규칙 5장](docs/PROTOCOL.md).
- 침대↔폰 연결(8080)은 침대 펌웨어가 정한 방식이라 잠글 수 없다.

## 개발자용

### 어떻게 동작하나

침대 제어 기판은 **Blynk Legacy** 방식으로 통신한다. 원래는 제조사 서버(birkits.blynk.cc)로 접속했는데,
침대를 설정할 때 **접속할 서버 주소를 직접 넣을 수 있다**는 점을 이용했다.

- 폰이 8080 포트로 Blynk 서버를 연다 (`BedServer.java` — 통신 규칙은 바꾸지 말 것)
- 설정 모드의 침대(192.168.4.1)에 집 와이파이와 **폰 주소**를 넣으면, 침대가 폰으로 접속해 온다
- 다른 폰은 UDP 9098 알림 신호로 서로를 찾고, HTTP 9099 로 명령을 중계한다 (`LanPeers`, `ApiServer`, `HomeKey`)

| 핀 | 뜻 | 값 |
|----|-----|------|
| V11 | 상체 각도 | 0~80 |
| V13 | 다리 각도 | 0~45 |
| V14 | 테이블 | 0~850 · 테이블 없는 제품은 다리가 움직인다 |
| V41 | **정지** | 1 (쓰기 전용) |
| V52 | 무드등 | 0/1 |
| V61 | 스피커 | 0/1 |
| V8, V15 | 미확인 | |

### 빌드

Gradle·AndroidX 없이 SDK 도구를 직접 부른다.

```
./build.sh 5.9.1      # → build/mabed-5.9.1.apk
```

- 필요: Android SDK(`ANDROID_HOME` 또는 `~/android-sdk`)의 build-tools 35.0.0 · platforms/android-35, JDK 17+
- 서명: `build/mabed.jks` + `build/ks_pass.txt` (**저장소에 없다. 잃어버리면 기존 설치본에 덮어쓸 수 없다**)

### 새 버전 내기

1. `AndroidManifest.xml` 의 `versionCode`(1 올림)와 `versionName` 수정, `docs/HISTORY.md` 에 기록
2. `main` 에 올리면 **점검**(`.github/workflows/check.yml`)이 돈다 — 비밀 유출 검사 · 컴파일 · 짝짓기 시험
3. 깃허브에서 `v<versionName>` 태그로 **릴리스 발행** → **APK 빌드**(`build.yml`)가 서명한 APK 를 릴리스에 붙인다
   (태그와 versionName 이 다르면 멈춘다). 금고(Secrets): `KEYSTORE_B64`, `KEYSTORE_PASS`
4. 폰의 앱이 켜질 때 새 릴리스를 찾아 설치할지 묻는다

### 시험

```
./test/pairing/run.sh <android.jar> <org.json.jar>
```

실제 `ApiServer`·`LanPeers`·`HomeKey`·`BedServer` 를 PC 에서 두 프로그램(서버 폰 / 요청 폰 + 가짜 침대)으로 돌려
짝짓기·도장·공격 흉내 35가지를 확인한다. 화면은 에뮬레이터 없이 확인할 수 없다.

### 꼭 지킬 것 (요약 — 전체는 CLAUDE.md)

- 저장 방식을 바꾸면 이전 설정을 옮기는 코드를 같이 (`migrateOld()`). 4.0.0 에서 등록한 침대가 전부 날아간 적이 있다.
- 포그라운드 서비스 종류는 `connectedDevice` (안드로이드 15 의 하루 6시간 제한 회피).
- `build.sh` 의 `--min-sdk-version 24 --target-sdk-version 35` 를 빼지 않는다.
- 정지는 V41 에 1. 서명 키·비밀번호는 저장소에 올리지 않는다(점검이 막는다).
